# Official sources for Go security

- Security overview: https://go.dev/doc/security/
- Go vulnerability management: https://go.dev/doc/security/vuln/
- govulncheck tutorial: https://go.dev/doc/tutorial/govulncheck
- govulncheck details: https://pkg.go.dev/golang.org/x/vuln/cmd/govulncheck
- Go modules: https://go.dev/ref/mod
- SQL driver and query contracts: https://pkg.go.dev/database/sql
- Filesystem paths: https://pkg.go.dev/path/filepath
- Executable/process API: https://pkg.go.dev/os/exec
- Network client/redirects: https://pkg.go.dev/net/http
- Cryptographic randomness: https://pkg.go.dev/crypto/rand

Check the actual Go/module/tool versions and the target's fixed `CODEX_PROJECT.md` scope before applying generic recommendations.
