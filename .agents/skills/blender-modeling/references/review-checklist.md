# Blender Modeling Review Checklist

- [ ] Dimensions/scale/origin satisfy project intent.
- [ ] Topology supports silhouette, shading, deformation, and UV needs.
- [ ] No accidental duplicate/degenerate/internal/loose geometry remains.
- [ ] Modifier stack/order and application state are intentional.
- [ ] Source versus evaluated geometry was distinguished.
- [ ] Face orientation and normals/shading are correct.
- [ ] UV seams, distortion, overlap, padding, and map ownership are intentional.
- [ ] Shape Keys/weights/attributes were checked before topology changes.
- [ ] High/low/cage/collision/LOD roles are unambiguous.
- [ ] No undeclared polygon/texel/LOD budget was introduced.
