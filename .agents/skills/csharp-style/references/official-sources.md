## Source precedence

`.editorconfig` and `CODEX_PROJECT.md` define the project policy. Microsoft conventions provide defaults for new/unconfigured code; they do not override an established repository.

When Unity is active, Unity serialization, generated project-file, analyzer, and callback constraints override style-only transformations.
