# Rigging And Animation Review Checklist

- [ ] Authoring/control/deform/export rig responsibilities are clear.
- [ ] Bone hierarchy/orientation/deform flags were reviewed.
- [ ] Weight quality was validated on representative poses.
- [ ] Constraint/IK/driver runtime assumptions are explicit.
- [ ] Action + Action Slot semantics are correct for Blender 5.2.
- [ ] NLA timing/blending/muting is intentional.
- [ ] Shape Key topology invariants are preserved.
- [ ] FPS, frame ranges, bake channels, and root ownership are explicit.
- [ ] Runtime bone/influence/root-motion limits come from target/project policy.
- [ ] Editable source animation was not destroyed without scope.
