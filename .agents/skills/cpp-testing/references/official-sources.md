# C++ testing sources

- CTest reference: https://cmake.org/cmake/help/latest/manual/ctest.1.html
- CMake enable_testing/add_test: https://cmake.org/cmake/help/latest/command/add_test.html
- GoogleTest documentation: https://google.github.io/googletest/
- Catch2 documentation: https://github.com/catchorg/Catch2
- doctest: https://github.com/doctest/doctest
- Clang AddressSanitizer: https://clang.llvm.org/docs/AddressSanitizer.html
- Clang UndefinedBehaviorSanitizer: https://clang.llvm.org/docs/UndefinedBehaviorSanitizer.html
- Clang ThreadSanitizer: https://clang.llvm.org/docs/ThreadSanitizer.html
- LLVM coverage: https://clang.llvm.org/docs/SourceBasedCodeCoverage.html
- MSVC AddressSanitizer: https://learn.microsoft.com/en-us/cpp/sanitizers/asan

Use versions already present in the target, not the latest test framework API examples as an unconditional requirement.
