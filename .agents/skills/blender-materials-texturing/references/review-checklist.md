# Materials And Texturing Review Checklist

- [ ] Render engine/color-management context is known.
- [ ] Material/node intent is separated from target-engine shader implementation.
- [ ] Every image's color-vs-data semantic role is known.
- [ ] File path/packing/dirty state was inspected.
- [ ] Painted/generated external images were saved where required.
- [ ] Bake source/target/UV/pass/margin/cage/output are explicit.
- [ ] Bake result was visually/data validated.
- [ ] Normal-map convention is declared.
- [ ] Roughness/Smoothness conversion is not conflated.
- [ ] Channel-packing ownership is documented.
- [ ] No undeclared texture-resolution/compression budget was introduced.
