# C++ style sources

- clang-format configuration and CLI: https://clang.llvm.org/docs/ClangFormat.html
- Clang style options: https://clang.llvm.org/docs/ClangFormatStyleOptions.html
- EditorConfig specification: https://editorconfig.org/
- C++ Core Guidelines: https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines
- Google C++ Style Guide: https://google.github.io/styleguide/cppguide.html
- Qt coding conventions, contextual (not universally enforced): https://wiki.qt.io/Qt_Coding_Style
- OBS Studio 33.0.1 project-specific CODESTYLE: https://github.com/obsproject/obs-studio/blob/33.0.1/CODESTYLE.md

Project style and exact tool version outrank example defaults. A syntax rule from a later C++ or Qt version is not automatically valid for this project.
